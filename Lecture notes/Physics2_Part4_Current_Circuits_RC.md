# 1. جریان الکتریکی

جریان الکتریکی میزان عبور بار الکتریکی از یک سطح در واحد زمان است.

تعریف جریان:

\[
\boxed{
I=\frac{dQ}{dt}
}
\]

برای جریان ثابت:

\[
\boxed{
I=\frac{Q}{t}
}
\]

واحد جریان:

\[
Ampere(A)
\]

جهت قراردادی جریان، جهت حرکت بار مثبت در نظر گرفته می‌شود.

---

# 2. چگالی جریان

چگالی جریان مقدار جریان عبوری از واحد سطح است:

\[
\boxed{
J=\frac{I}{A}
}
\]

واحد:

\[
A/m^2
\]

رابطه با سرعت رانشی:

\[
\boxed{
J=nqv_d
}
\]

که:

- \(n\): تعداد حامل‌های بار در واحد حجم
- \(q\): بار هر حامل
- \(v_d\): سرعت رانشی

---

# 3. سرعت رانشی الکترون‌ها

در یک رسانا، الکترون‌ها حرکت تصادفی دارند، اما در حضور میدان الکتریکی یک سرعت متوسط در یک جهت پیدا می‌کنند که سرعت رانشی نام دارد.

رابطه جریان:

\[
I=nqAv_d
\]

---

# 4. مقاومت الکتریکی

مقاومت یک رسانا در برابر عبور جریان الکتریکی است.

تعریف:

\[
\boxed{
R=\frac{V}{I}
}
\]

واحد:

\[
Ohm(\Omega)
\]

---

# 5. قانون اهم

برای بسیاری از رساناها:

\[
\boxed{
V=IR
}
\]

در این حالت مقاومت ثابت است.

نمودار ولتاژ بر حسب جریان خطی است.

---

# 6. مقاومت ویژه

مقاومت یک سیم به جنس و ابعاد آن وابسته است.

رابطه:

\[
\boxed{
R=\rho\frac{L}{A}
}
\]

که:

- \(\rho\): مقاومت ویژه ماده
- \(L\): طول سیم
- \(A\): سطح مقطع

واحد مقاومت ویژه:

\[
\Omega.m
\]

---

# 7. تغییر مقاومت با دما

مقاومت فلزات معمولاً با افزایش دما زیاد می‌شود:

\[
\boxed{
R=R_0[1+\alpha(T-T_0)]
}
\]

که:

- \(\alpha\): ضریب دمایی مقاومت

---

# 8. توان الکتریکی

توان میزان مصرف یا انتقال انرژی الکتریکی در واحد زمان است.

\[
\boxed{
P=\frac{W}{t}
}
\]

روابط مهم:

\[
P=VI
\]

با استفاده از قانون اهم:

\[
\boxed{
P=I^2R
}
\]

و:

\[
\boxed{
P=\frac{V^2}{R}
}
\]

واحد:

\[
Watt(W)
\]

---

# 9. مدارهای الکتریکی

## اتصال سری

در مدار سری:

جریان همه اجزا برابر است:

\[
I=I_1=I_2=...
\]

مقاومت معادل:

\[
\boxed{
R_{eq}=R_1+R_2+...
}
\]

ولتاژ تقسیم می‌شود.

---

## اتصال موازی

در مدار موازی:

ولتاژ همه شاخه‌ها برابر است:

\[
V=V_1=V_2=...
\]

مقاومت معادل:

\[
\boxed{
\frac1{R_{eq}}
=
\frac1{R_1}
+
\frac1{R_2}
+...
}
\]

جریان تقسیم می‌شود.

---

# 10. نیروی محرکه الکتریکی

باتری‌ها انرژی غیرالکتریکی را به انرژی الکتریکی تبدیل می‌کنند.

نیروی محرکه:

\[
\boxed{
\varepsilon=\frac{W}{q}
}
\]

در مدار دارای مقاومت داخلی:

\[
V=\varepsilon-Ir
\]

که:

- \(r\): مقاومت داخلی باتری

---

# 11. قوانین کیرشهف

## قانون اول کیرشهف

قانون گره:

مجموع جریان‌های واردشونده به یک گره برابر مجموع جریان‌های خارج‌شونده است.

\[
\boxed{
\sum I=0
}
\]

---

## قانون دوم کیرشهف

قانون حلقه:

مجموع تغییرات پتانسیل در یک مسیر بسته صفر است.

\[
\boxed{
\sum \Delta V=0
}
\]

---

# 12. مدار RC

مدار RC شامل:

- مقاومت \(R\)
- خازن \(C\)

است.

ثابت زمانی مدار:

\[
\boxed{
\tau=RC
}
\]

---

# 13. شارژ خازن در مدار RC

ولتاژ خازن هنگام شارژ:

\[
\boxed{
q(t)=C\varepsilon(1-e^{-t/RC})
}
\]

ولتاژ:

\[
\boxed{
V_C=\varepsilon(1-e^{-t/RC})
}
\]

جریان:

\[
\boxed{
I=I_0e^{-t/RC}
}
\]

---

# 14. تخلیه خازن

در تخلیه:

\[
\boxed{
q(t)=Q_0e^{-t/RC}
}
\]

و:

\[
\boxed{
I=I_0e^{-t/RC}
}
\]

---

# خلاصه فرمول‌های مهم

## جریان

\[
I=\frac{Q}{t}
\]

## چگالی جریان

\[
J=\frac IA
\]

## قانون اهم

\[
V=IR
\]

## مقاومت سیم

\[
R=\rho\frac LA
\]

## توان

\[
P=VI=I^2R=\frac{V^2}{R}
\]

## سری مقاومت‌ها

\[
R_{eq}=\sum R_i
\]

## موازی مقاومت‌ها

\[
\frac1{R_{eq}}=\sum\frac1{R_i}
\]

## ثابت زمانی RC

\[
\tau=RC
\]

## شارژ RC

\[
q=Q(1-e^{-t/RC})
\]

## تخلیه RC

\[
q=Q_0e^{-t/RC}
\]
