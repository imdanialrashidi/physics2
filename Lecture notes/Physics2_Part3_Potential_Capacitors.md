# 1. پتانسیل الکتریکی

میدان الکتریکی باعث ایجاد نیرو بر بارها می‌شود. برای جابه‌جایی یک بار در میدان الکتریکی، کار انجام می‌شود.

کار میدان:

\[
W=\int \vec F\cdot d\vec s
\]

از آنجا که:

\[
\vec F=q\vec E
\]

داریم:

\[
W=q\int \vec E\cdot d\vec s
\]

اختلاف پتانسیل بین دو نقطه:

\[
\boxed{
V_B-V_A=-\int_A^B \vec E\cdot d\vec s
}
\]

واحد پتانسیل:

\[
Volt=\frac{J}{C}
\]

---

# 2. پتانسیل ناشی از بار نقطه‌ای

برای یک بار نقطه‌ای:

\[
E=\frac{kq}{r^2}
\]

پس:

\[
V=-\int E dr
\]

نتیجه:

\[
\boxed{
V=\frac{kq}{r}
}
\]

ویژگی‌ها:

- پتانسیل کمیت نرده‌ای است.
- جهت ندارد.
- برای چند بار با جمع جبری محاسبه می‌شود.

---

# 3. پتانسیل چند بار نقطه‌ای

اگر چند بار داشته باشیم:

\[
\boxed{
V=k\sum_i\frac{q_i}{r_i}
}
\]

برخلاف میدان الکتریکی، پتانسیل‌ها برداری جمع نمی‌شوند.

---

# 4. انرژی پتانسیل الکتریکی

انرژی پتانسیل یک بار در میدان:

\[
U=qV
\]

برای دو بار نقطه‌ای:

\[
\boxed{
U=\frac{kq_1q_2}{r}
}
\]

اگر:

- \(q_1q_2>0\) : انرژی مثبت
- \(q_1q_2<0\) : انرژی منفی

---

# 5. رابطه میدان و پتانسیل

رابطه کلی:

\[
\boxed{
\vec E=-\nabla V
}
\]

در یک بعد:

\[
E=-\frac{dV}{dx}
\]

یعنی میدان در جهت کاهش پتانسیل است.

---

# 6. خازن

خازن وسیله‌ای برای ذخیره انرژی الکتریکی است.

ساختار ساده:

- دو رسانا
- بین آن‌ها عایق یا دی‌الکتریک

ظرفیت خازن:

\[
\boxed{
C=\frac{Q}{V}
}
\]

واحد:

\[
Farad(F)
\]

---

# 7. خازن صفحات موازی

برای دو صفحه موازی:

\[
\boxed{
C=\frac{\epsilon_0 A}{d}
}
\]

که:

- \(A\): مساحت صفحات
- \(d\): فاصله صفحات

اگر دی‌الکتریک با ضریب:

\[
\kappa
\]

قرار گیرد:

\[
\boxed{
C=\frac{\kappa\epsilon_0 A}{d}
}
\]

---

# 8. انرژی ذخیره شده در خازن

کار لازم برای شارژ خازن:

\[
W=\int Vdq
\]

و نتیجه:

\[
\boxed{
U=\frac12 CV^2
}
\]

فرم‌های دیگر:

\[
U=\frac12 QV
\]

و:

\[
U=\frac{Q^2}{2C}
\]

---

# 9. اتصال خازن‌ها

## خازن‌های موازی

در اتصال موازی:

ولتاژ همه برابر است:

\[
V=V_1=V_2=...
\]

ظرفیت معادل:

\[
\boxed{
C_{eq}=C_1+C_2+...
}
\]

---

## خازن‌های سری

در اتصال سری:

بار همه خازن‌ها برابر است:

\[
Q=Q_1=Q_2=...
\]

ولتاژ تقسیم می‌شود:

\[
V=V_1+V_2+...
\]

ظرفیت معادل:

\[
\boxed{
\frac1{C_{eq}}
=
\frac1{C_1}
+
\frac1{C_2}
+...
}
\]

---

# 10. دی‌الکتریک‌ها

قرار دادن ماده عایق بین صفحات خازن باعث افزایش ظرفیت می‌شود.

ثابت دی‌الکتریک:

\[
\kappa
=
\frac{C}{C_0}
\]

پس:

\[
C=\kappa C_0
\]
