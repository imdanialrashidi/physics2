# فیزیک ۲ — پارت دوم
# فایل ۴: میدان مغناطیسی، نیروی مغناطیسی و قانون آمپر

## مباحث این فایل

- میدان مغناطیسی
- نیروی وارد بر بار متحرک
- حرکت ذره باردار در میدان مغناطیسی
- نیروی وارد بر سیم حامل جریان
- گشتاور مغناطیسی
- قانون بیو-ساوار
- قانون آمپر
- میدان ناشی از سیم، حلقه و سلونوئید

---

# 1. میدان مغناطیسی

میدان مغناطیسی ناحیه‌ای از فضا است که بر بارهای متحرک و جریان‌های الکتریکی نیرو وارد می‌کند.

میدان مغناطیسی را با:

\[
\vec B
\]

نشان می‌دهیم.

واحد میدان مغناطیسی:

\[
Tesla(T)
\]

است.

---

# 2. نیروی مغناطیسی وارد بر بار متحرک

اگر ذره‌ای با بار q با سرعت v وارد میدان مغناطیسی شود:

\[
\boxed{
\vec F=q\vec v\times\vec B
}
\]

اندازه نیرو:

\[
\boxed{
F=qvB\sin\theta
}
\]

که θ زاویه بین سرعت و میدان است.

حالت‌ها:

اگر:

\[
\theta=0
\]

باشد:

\[
F=0
\]

یعنی حرکت موازی میدان نیروی مغناطیسی ایجاد نمی‌کند.

اگر:

\[
\theta=90^\circ
\]

باشد:

\[
F=qvB
\]

و نیرو بیشینه است.

---

# 3. قاعده دست راست

جهت نیرو از حاصل‌ضرب برداری تعیین می‌شود:

- انگشت‌ها در جهت سرعت
- چرخش به سمت میدان
- انگشت شست جهت نیروی بار مثبت

برای بار منفی جهت نیرو مخالف است.

---

# 4. حرکت ذره باردار در میدان مغناطیسی

چون نیرو عمود بر سرعت است، کار انجام نمی‌شود.

بنابراین:

- اندازه سرعت ثابت می‌ماند.
- مسیر می‌تواند دایره‌ای شود.

نیروی مرکزگرا:

\[
F=\frac{mv^2}{r}
\]

و نیروی مغناطیسی:

\[
qvB=\frac{mv^2}{r}
\]

پس شعاع مسیر:

\[
\boxed{
r=\frac{mv}{qB}
}
\]

---

# 5. فرکانس حرکت دایره‌ای

زمان تناوب:

\[
T=\frac{2\pi r}{v}
\]

با جایگذاری:

\[
\boxed{
T=\frac{2\pi m}{qB}
}
\]

فرکانس زاویه‌ای:

\[
\boxed{
\omega=\frac{qB}{m}
}
\]

---

# 6. حرکت مارپیچی

اگر سرعت دارای دو مؤلفه باشد:

- مؤلفه عمود بر میدان → حرکت دایره‌ای
- مؤلفه موازی میدان → حرکت مستقیم

ترکیب آن‌ها باعث مسیر مارپیچی می‌شود.

---

# 7. نیروی مغناطیسی وارد بر سیم حامل جریان

برای سیمی با جریان I در میدان مغناطیسی:

\[
\boxed{
\vec F=I\vec L\times\vec B
}
\]

اندازه:

\[
\boxed{
F=ILB\sin\theta
}
\]

---

# 8. گشتاور روی حلقه جریان‌دار

حلقه جریان‌دار در میدان مغناطیسی گشتاور دریافت می‌کند.

\[
\boxed{
\tau=NIAB\sin\theta
}
\]

که:

- N تعداد دور
- A مساحت حلقه
- I جریان

گشتاور مغناطیسی:

\[
\boxed{
\mu=NIA
}
\]

پس:

\[
\tau=\mu B\sin\theta
\]

---

# 9. قانون بیو-ساوار

برای المان جریان:

\[
d\vec B
=
\frac{\mu_0}{4\pi}
\frac{Id\vec l\times\hat r}{r^2}
\]

این قانون میدان مغناطیسی ناشی از جریان‌های کوچک را بیان می‌کند.

---

# 10. میدان سیم مستقیم بلند

برای سیم بلند حامل جریان:

\[
\boxed{
B=\frac{\mu_0 I}{2\pi r}
}
\]

که:

\[
\mu_0=4\pi\times10^{-7}
\]

است.

جهت میدان با قاعده دست راست تعیین می‌شود.

---

# 11. میدان مرکز حلقه جریان

برای یک حلقه دایروی:

\[
\boxed{
B=\frac{\mu_0 I}{2R}
}
\]

برای N دور:

\[
\boxed{
B=\frac{\mu_0 NI}{2R}
}
\]

---

# 12. قانون آمپر

قانون آمپر:

\[
\boxed{
\oint \vec B\cdot d\vec l
=
\mu_0 I_{enc}
}
\]

که:

\[
I_{enc}
\]

جریان محصور داخل مسیر آمپری است.

---

# 13. میدان داخل سلونوئید

برای سیم‌پیچ بلند:

\[
\boxed{
B=\mu_0 nI
}
\]

که:

\[
n=\frac NL
\]

تعداد دور در واحد طول است.

---
